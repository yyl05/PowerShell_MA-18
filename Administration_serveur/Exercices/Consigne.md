# Exercice PowerShell : Lister les services arrêtés

**Objectif :** Utiliser PowerShell pour identifier et afficher les services Windows qui ne sont pas en cours d’exécution.

**Consignes :**
1. Récupérez la liste de tous les services du système.
2. Filtrez uniquement ceux dont le **statut est “Stopped”**.
3. Affichez à l’écran un titre clair : `"Services arrêtés :"`.
4. Affichez le **nom** et le **statut** de chaque service arrêté.
